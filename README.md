# ממן מטלות 🏠

אפליקציית ניהול מטלות בית משפחתיות — כולם רואים, כולם עוזרים.

## מה זה?

אפליקציית web משפחתית לניהול מטלות שבועיות. כל אחד נכנס עם 4 ספרות של מספר הטלפון שלו, מסמן מטלות, ורואה מה אחרים כבר עשו — הכל מסונכרן בזמן אמת.

## פיצ'רים

- כניסה מהירה עם 4 ספרות
- מטלות קבועות לשלישי / שישי / מוצ"ש
- הוספת מטלות מותאמות אישית לכל יום
- מטלות נמחקות אוטומטית אחרי יומיים
- סנכרון בזמן אמת בין כל הטלפונים
- dark mode
- RTL עברית מלאה

## טכנולוגיות

- React 18 (CDN)
- Firebase Realtime Database
- TailwindCSS (CDN)
- nginx + Docker
- Railway (hosting)
